# 架构说明

## 一、根干枝叶四层生命架构

```
┌─────────────────────────────────────────────┐
│ 树叶层  自主进化 · 全息审视 · 元思考 · 可视化   │
├─────────────────────────────────────────────┤
│ 树枝层  Agent母体 · 文曲星创作 · 内生安全 · 蜂群联邦 │
├─────────────────────────────────────────────┤
│ 树干层  卦象决策 · 万魂熔炉 · NLP七层 · 八门系统  │
├─────────────────────────────────────────────┤
│ 种子层  脉冲呼吸 · 五蕴观测 · 定力调节 · 悔恨驱动  │
└─────────────────────────────────────────────┘
```

## 二、运行时主循环

内核 `breathe_cycle` 每一轮呼吸执行：

1. **一体呼吸**：呼吸计数 +1；
2. **五蕴观测**：采集六项指标（CPU / 内存 / 磁盘IO / 网络 / 模型延迟 / 进程数），加权得到痛苦指数；
3. **定力调节**：痛苦指数高则定力衰减，平和则定力回升；
4. **卦象推演**：天地人（体）× 正合反（用）× 合人天（变）生成当前卦象；
5. **脉冲呼吸**：观测 / 苦受 / 自愈 / 进化 / 觉悟神经元按阈值与冷却触发；
6. **三空约束**：卦象防漂移、资源留白、身份复盘周期校验；
7. **八门联动**：按卦象映射表对各门插件下发 activate / deactivate；
8. **周期任务**：每 100 次呼吸做四象协调与悔恨复盘；每 500 次呼吸做六合自省；
9. **自适应休眠**：按脉冲结果调整下一次呼吸间隔（3–20 秒）。

## 三、模块职责

| 模块 | 文件 | 职责 |
|------|------|------|
| 插件基类 | `core/plugin_base.py` | 统一 `on_activate` / `on_command` 接口 |
| 1-9 引擎 | `core/engines_1to9.py` | 体系结构与状态定义 |
| 深化引擎 | `core/deep_core.py` | 脉冲、十二自、三空、四象、六指标、六合、Agent、八门、共生 |
| 主内核 | `core/kernel.py` | 循环调度、卦象、插件生命周期、对话编排 |
| LLM 客户端 | `llm/client.py` | 双底座、熔断器、重试、降级 |
| 悔恨存储 | `memory/regret_store.py` | SQLite 安全短连接 |
| API | `api/app.py` | 路由 + 仪表盘 |

## 四、设计约束与已修复的工程风险

- **SQLite 并发安全**：每次读写打开独立连接、用完即关，不跨任务持有；
- **LLM 阻塞隔离**：熔断器在连续失败后进入冷却，冷却期直接降级，不阻塞主呼吸循环；
- **插件故障隔离**：单个插件加载/执行失败被记录并禁用，不阻止内核觉醒；
- **配置外置**：阈值、端口、模型名、权重全部在 `config/config.yaml`，代码不写死；
- **密钥不入库**：豆包 API Key 仅从环境变量 `ARK_API_KEY` 读取。
