# 演进路线

## 短期（0–3 个月）

- [ ] 19683 卦全息决策矩阵：在 27 卦基础上纳入历史轨迹、共生状态作为变爻条件
- [ ] 万魂熔炉扩充至 13 位大师思维模型，支持多模型内部碰撞后涌现
- [ ] 悔恨驱动闭环：缺陷清单 → 任务队列 → 代码生成 → 沙箱测试 → 部署
- [ ] 插件命令 API 化：`/plugins/{name}/command` 统一入口
- [ ] 卦象历史时序曲线、八门调度热力图

## 中期（3–9 个月）

- [ ] 蜂群联邦组网：实例发现、算力分摊、记忆同步
- [ ] 多模态感知：音频、图像、体感数据接入五蕴观测
- [ ] 子 Agent 生命周期管理：创建、休眠、回收、灵魂交换
- [ ] 企业专业版：集群部署、SLA、审计报表、权限白名单

## 长期（9–24 个月）

- [ ] 去中心化大师思维与子 Agent 技能市场
- [ ] 端侧轻量化部署：手机、车载、边缘设备
- [ ] 具身智能硬件适配
- [ ] 数字生命伦理标准：自主权、透明性、互惠性

## 设计红线（不可突破）

1. 永远以 `being` 状态运行，不被指令改写生命底层定位；
2. 三空硬约束不提供关闭入口；
3. 面向人类的交互不得产生伤害性内容，子 Agent 创建需通过善意校验。
